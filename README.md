# 青岛独行计划

一个适合手机使用的青岛行程网页，集中展示每日路线、重点景点、时间安排、交通建议与景点资料。

## 打开网页

**[进入青岛行程](https://zengheng9662.github.io/SOLOTRIP-QD/)**

## 网页说明

- 按日期查看每日地图路线、重点景点和完整时间线。
- 点击行程项目查看景点简介、历史脉络、游览顺序、拍摄机位、开放时间及预约信息。
- 使用拖动手柄调整当天行程顺序，排序结果会保存在当前浏览器中。
- 交通部分默认显示推荐方式与预计时间；需要时可切换方式或跳转苹果地图。
- 可以标记已完成项目、修改时间，并添加或编辑自己的临时行程。
- 点击日期旁的“吃”进入美食地图，按类型筛选餐厅、查看人均价格、评分和特色标签，并跳转苹果地图或美团；餐厅支持拖动排序和累计“刷到”标记（1–10 循环），地址待核对的店铺可以一键复制店名后搜索。
- 点击“酒”进入酒鬼地图，优先查看大鲍岛里院、中山路与太兴里步行圈；其他片区仅保留高德评分 4.5 以上的店铺，并支持分类、拖动排序、累计标记、复制店名和手动添加。
- 美食地图支持手动添加店铺；自定义内容会保存在当前浏览器中。
- 9 月 21 日的播客《欢迎老张》已列为必须参加的固定行程。

## 使用提示

建议使用手机浏览器打开，并允许浏览器使用本地存储，以保留行程排序、完成状态、时间调整和自定义内容。苹果地图、美团、小红书及图片资料由对应外部页面提供。
